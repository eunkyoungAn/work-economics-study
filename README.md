# 일의 세계 경제학 · 오픈북 학습실

제공된 조우현 『일의 세계 경제학』 제2판의 제3·10·11장 및 보론 발췌본을 재서술한 학습자료입니다.

- 24개 핵심 주제와 학습 개요
- 시험 답안 문체로 정리한 48개 모범답안과 미니시험 12문항
- 본문 쪽수 / PDF 실제 순서 / 원문 소제목·식·표·그림 색인
- 주제별 필기, 개인 답안, 복습 상태 저장 및 JSON 백업·복원
- [59쪽 학습노트 PDF](study-notes.pdf)
- [원문 대조 검토표](answer-review.md)

원문 수치와 설명을 우선하며 의심되는 불일치는 ‘확인 필요’로 표시합니다. 임의 정정값을 정답으로 사용하지 않습니다. 모범답안은 실제 기출문제나 공식 정답이 아닙니다.

‘원문 PDF 연결’에서 보유한 원문을 선택하면 쪽수 버튼으로 원문을 열 수 있습니다. 파일은 서버에 업로드되지 않습니다. 새로고침 후 다시 연결해야 하며 뷰어에 따라 표시된 PDF 쪽수를 직접 입력해야 할 수 있습니다.

필기는 현재 브라우저에만 저장됩니다. 기기 간 자동 동기화되지 않으므로 백업 파일을 내려받아 옮기세요. 백업 복원은 기존 기록과 합치고, 같은 항목은 불러온 기록으로 갱신합니다. 복원 전 기존 기록을 자동으로 백업합니다.

## 학습 순서
개요 확인 → 핵심 내용 읽기 → 책을 덮고 답안 작성 → 모범답안과 원문 대조 → 빠진 핵심어 기록 → 다음 날 재시험.

공개 배포에는 학습용 재서술 자료만 포함하며, 제공된 원문 PDF·스캔 이미지·개인 필기는 포함하지 않습니다.


## 2026-10-20 기업 실무 보충

주제 01의 Q1을 학력·채용·임금 종합 문항으로 보완했습니다. 원문 p.45~48에 근거한 네 가지 이유와 기업 실무 적용 해설, IBM의 2020년 공개 경험 및 HBS·Burning Glass의 2024년 연구를 구분해 수록했습니다. 원문 기반 답안과 실무 확장은 별도 표시합니다.

기존 PDF 1~56쪽은 원래 쪽수와 색인을 유지하고, 기업 실무 보충 57~59쪽을 추가했습니다. 웹·Markdown·PDF는 같은 공통 보충 데이터를 사용합니다.
